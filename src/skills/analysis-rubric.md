# 分析量表

## 证据等级

- **E3：直接事实**：原始公告、监管/合同文件、链上或产品日志、可重复的公开数据。
- **E2：一手但未独立核验**：项目方、当事人、现场参与者或明确时间地点的截图/帖子。
- **E1：二手分析**：KOL 的解释、媒体转述、基于数据的推断。
- **E0：噪声/不可核验**：闲聊、情绪、口号、纯推广、无上下文图片或匿名传闻。

互动量、粉丝数和“知名 KOL”标签不能把 E0/E1 自动升级。若一条帖子同时包含事实与判断，拆成两条证据。

## KOL 信号检查

检查具体性（是否包含对象、时间、机制）、可追溯性、历史命中记录、利益披露、是否有可验证的行为/持仓/产品使用、是否存在反向激励。把 KOL 的传播能力与判断质量分开记录。

## 评分

六项各 0–5 分：

1. 信号强度：变化是否明确、异常、与基线有差异。
2. 证据质量：从 E0 到 E3，且是否有独立来源。
3. 时间窗口：催化剂/需求窗口是否清晰且仍开放。
4. 规模：潜在资金、用户或成本是否足够大。
5. 可执行性/差异化：能否在权限、资源和时间约束内验证或交付。
6. 下行风险：5 表示风险已被较好限制，0 表示存在不可接受或不可量化的风险。

总分不是成功概率。任何核心主张只有单一来源时，置信度最多为“中”；涉及匿名指控、低流动性资产或不可逆迁移时，置信度最多为“低”，直到完成独立验证。

## 通用机会字段

```text
id, type, title, thesis, trigger, target, mechanism,
evidence[], confidence, score{signal,evidence,window,scale,execution,downside,total},
validation_action, falsifier, stop_condition, risks, time_horizon, conflicts
```

## 四类机会的最小判定

### 交易

必须能写出催化剂、受益/受损资产、传导机制、时间窗、流动性与拥挤度、失效条件。缺少可交易对象或退出路径时，降级为“主题观察”。

### 产品

必须能写出目标用户、具体任务/痛点、现有替代、价值指标、最小可行切入点、获客路径和潜在付费方。只有“大家都在讨论”不足以证明需求。

### 工具

必须能写出重复流程、输入输出、人工成本/错误成本、所需数据源和集成边界。优先寻找监控、验证、路由、合规、研究和协作等可重复任务。

### 替代

必须能写出现有方案、用户为何不满、迁移触发器、迁移成本、最小性能/信任门槛和切入市场。单纯“更便宜/更快”要有可验证的比较基线。
